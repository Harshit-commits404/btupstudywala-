# BTEUP Study Platform

> A digital study platform and textbook notes companion designed specifically for BTEUP (Board of Technical Education Uttar Pradesh) polytechnic diploma engineering students.

## 🚀 Features

- **Semester & Subject Selection**: Covers Semester 1, 3, and 5 diploma subjects.
- **Digital Textbook & Typed Notes Experience**: High-readability long-form reading canvas, structured chapter navigation, and clean academic hierarchy.
- **Dedicated Mathematical Formula Presentation**: Rendered with scientific serif typography (**STIX Two Text**), variable breakdowns, and subtle ambient glow.
- **Bilingual Concepts**: English academic terminology with intuitive Hinglish concept clarifications.
- **Board Exam Preparation**: High-yield model questions grouped by mark weightage (1 Mark, 2–3 Marks, 5 Marks derivations).
- **Last Minute Quick Revision**: Summary sheets and core takeaways for rapid revision.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Routing**: React Router v7 (with Vercel SPA rewrites)
- **Styling**: Tailwind CSS + Custom Typography
- **Icons**: Lucide React
- **Deployment**: Vercel

## 📦 Project Setup

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```

## 🌐 Deployment Settings (Vercel)

- **Framework Preset**: Vite
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
- **Install Command**: `npm install`
- **SPA Fallback**: Configured via `vercel.json`
